# Creative Program

This lab should not stay locked to the organ series.

The organ/grotesque direction is useful, but it is now one lane inside a broader generative 3D program. Daily work should rotate between lanes unless the user explicitly asks to stay in one.

## Active Lanes

### 1. Visceral Architecture

Abstract organs, membranes, ducts, cavities, valves, folds, and wet contact forms. Avoid thin decorative vessel lines. Use this lane when the goal is grotesque, biological, dark, or tactile.

### 2. Mineral / Fossil / Bone

Porous shells, eroded lattices, bone-white structures, calcified ribs, coral-stone hybrids, and fossil-like voids. This lane should bring back perforation, hardness, and print-friendly negative space.

### 3. Textile / Membrane / Skin

Suspended sheets, pleated curtains, layered films, sagging translucent skins, stitched seams, and tension surfaces. This lane should feel lighter and more spatial than organ blobs.

### 4. Machine / Instrument / Ritual Object

Radial clamps, valve-like mechanisms, impossible tools, masks, handles, tuning-fork bodies, rotating parts, and altar-like objects. This lane can be darker and more constructed.

### 5. Growth / Plant / Marine

Kelp, spores, anemones, seed pods, reef columns, manta shells, fronds, and current-carved surfaces. This lane should recover the earlier organic beauty without becoming generic.

### 6. VJ Motion Form

Objects designed primarily for rotation, looping silhouettes, transparent PNG compositing, and future MP4/alpha assets. The form can be simpler if the motion language is stronger.

### 7. Print Object / Product Candidate

Lamp shells, vases, pendants, wall pieces, small sculptures, and modular objects. This lane should emphasize stable thickness, clean underside, useful openings, and recognizable object presence.

## Rotation Rule

Do not spend more than three consecutive daily runs in the same lane unless the user asks for a focused series.

When a lane repeats, the construction method must change. For example, a visceral piece after another visceral piece should move from soft mass to lattice, cutaway, membrane sheet, or structural bundle.

## Concept Source

Concept exploration can happen in this Codex thread or in ChatGPT.

Use this Codex thread when the idea should immediately become scripts, reports, assets, site updates, automation rules, or production decisions.

Use ChatGPT when the goal is wide-open naming, mood boards, references, language, market positioning, or long-form concept brainstorming before production.

The default for daily production is: decide enough here, build, publish, and then revise from what is visible.
