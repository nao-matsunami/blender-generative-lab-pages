# Offset Contour Lantern

外半径 r=64+Lᵢ+12cos(4θ+0.18i)+14u cos(θ−0.6) mm、u=z/168、i=floor(z/28)、Lᵢ=[0,11,22,8,−3,−13] mm。高さ42/70/98/126 mmに幅15 mmの水平開口を設け、各段の3支持部を0.31 radずつ回す。名目肉厚3.4 mm、支持部の角半幅0.22 rad。下部20 mmは連続接地帯。STL外接寸法197.29 × 196.91 × 168.00 mm、支持部の計画最小幅は内周側で約20 mm。底面をLEDの出し入れ候補、上端を通気・光の開口として残す。

初回GUIレンダーは段差と四角い輪郭の起伏が弱かった。段の張り出し、四回対称の起伏、上部の偏心、画角を強めて再レンダー。最終PNGで主要部のクリッピング、浮いた部品、暗すぎる階層を確認した。前作から、先細りシェルを偏心した六つの輪郭段に、楕円穴を四つの水平通気路に、青灰色を温かい石灰色に変更し、カメラも横側へ移した。

STLとGLBはBlender GUIから出力。Eteviaタッチライトの掲載幅70 mmと充電式E26電球を参照するが、現物の寸法・操作・充電・保持・換気・発熱は未確認。固定方法は未確定。段の張り出し、開口上面、層方向の強度、接地安定性はスライサーと実物試験が必要。電気・熱試験も未実施の造形デザイン習作。

作品GLBと仮想内部点光源で床・背面壁への投影を表示。高さ、相対光量、色、回転を操作可能。これは理想的な点光源の形状確認であり、Eteviaまたは充電式E26の実測配光、照度、透過、温度を表さない。
